# Splash image sources

`nixos.bmp` is a 128×128, uncompressed 24-bit BMP converted from
[`nix-snowflake-colours.svg`](https://github.com/NixOS/nixos-artwork/blob/master/logo/nix-snowflake-colours.svg)
from the NixOS artwork repository. The NixOS logo is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`linux.bmp` is a 128×128, uncompressed 24-bit BMP converted from
[`tux-large.png`](https://github.com/garrett/Tux/blob/main/tux-large.png).
That artwork is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
